# Novyra Lead Intelligence Dashboard

Standalone portfolio project.

## Run
1. Extract the ZIP.
2. Open the `novyra-lead-dashboard` folder in VS Code.
3. Open `index.html`.
4. Click **Go Live**.

No Node.js, npm, terminal, or installation required.

## Features
- Responsive SaaS dashboard
- Lead pipeline table
- Lead scoring and opportunity levels
- Search and score filters
- Outreach queue
- Add lead modal with working UI
- Analytics visualizations
